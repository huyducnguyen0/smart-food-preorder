# Sprint Management

Mỗi Sprint tạo một thư mục riêng theo mẫu `Sprint-<NN>/` và lưu:

- Sprint Goal.
- Sprint Backlog tại thời điểm planning.
- Capacity/availability của team.
- Task breakdown và owner.
- Thay đổi phạm vi trong Sprint.
- Link tới Task Board, Pull Request và increment.

Task Board dùng các trạng thái tối thiểu:

```text
Backlog → To Do → In Progress → Review → Done
```

Không chuyển task sang `Done` nếu Definition of Done trong `CONTRIBUTING.md` chưa đạt.
