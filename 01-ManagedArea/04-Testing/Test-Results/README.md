# Test Results

Lưu kết quả theo build/release, không ghi đè bằng chứng cũ.

Mỗi báo cáo cần có:

- version/commit/build được test;
- môi trường và cấu hình;
- bộ test đã chạy;
- số lượng Passed/Failed/Blocked;
- defect liên quan;
- giới hạn của kết quả;
- quyết định có đủ điều kiện release hay không.
