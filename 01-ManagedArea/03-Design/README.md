# Analysis and Design
Input: SRS, Use Case Specification và Activity Diagram.

Theo Bước 11–14:
1. Analysis Model: Boundary/Controller/Entity, phân bổ trách nhiệm và Sequence Diagram.
2. Architecture: kiến trúc, Package Diagram và trách nhiệm thành phần.
3. Detailed Design: ERD, Relational Schema và Detailed Class Diagram.
4. UI Prototype: layout, wireframe, phối màu, navigation, đánh giá và chỉnh sửa.

Các output được làm rõ cho phạm vi triển khai và cập nhật qua các Sprint.
