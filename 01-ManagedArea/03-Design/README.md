# 03 - Analysis and Design

## Thứ tự

```text
Use Case + Activity
→ Analysis Model
→ Architecture + ADR
→ Database/Class Design
→ UI Prototype
→ Implementation-ready design
```

Không khóa framework hoặc database trước khi các quality attribute và luồng cốt lõi được hiểu đủ rõ. Mọi quyết định có trade-off đáng kể phải có ADR.
