# Use Cases
Trạng thái: Chưa xây dựng.

Input: SRS, danh sách chức năng và vai trò người dùng.
Thực hiện: xác định actor → xác định Use Case → sơ đồ tổng quan → phân rã khi cần.

Output:
- Actor List.
- Use Case List.
- Use Case Diagram.
- Decomposed Use Case Diagram khi cần.
- Use Case Specification theo mẫu trong thư mục.

Các output dùng cho Activity, Analysis, UI và Test Case.
