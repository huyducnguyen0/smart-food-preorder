# Coding Convention

Trạng thái: `Deferred until technology stack is approved`

Tài liệu này phải được hoàn thiện trước Sprint implementation đầu tiên và cần bao gồm:

- cấu trúc module/package;
- naming cho file, class, function, biến và database object;
- indentation, whitespace, line length và import;
- error handling, validation và logging;
- comment/documentation;
- security và secret handling;
- test naming/organization;
- formatter, linter và static analysis bắt buộc;
- quy tắc commit/PR liên quan đến source code.

Không sao chép nguyên convention chung của một ngôn ngữ mà không ghi rõ các quy tắc bổ sung riêng của dự án.
