# Coding Convention
Trạng thái: Mẫu chưa hoàn thành; chưa chọn ngôn ngữ/công nghệ.

Theo Bước 15 của nguồn, cần thống nhất:
- Indentation.
- Whitespace.
- Line length.
- Naming.
- Declaration.
- Expression.
- Comment.
- Documentation.

Project mẫu trong nguồn dùng Java và tham khảo convention của Sun. Dự án chưa chọn convention cụ thể.
